# 无名战神 · 开发方向与迭代路线

## 不变的产品方向
玩家创建自己的无名武将，亲自进入敌我交战的大战场，通过杀敌升级、拾取并穿戴装备、形成自己的构筑，逐渐从新卒成长到能横扫军阵的战神，最后主动挑战敌方统帅。水墨国风轻量 3D，H5，横屏宽高比 20:9。不是固定扮演赵云，也不是站桩自动攻击的幸存者换皮。

基础模式已在本分支接入：本地角色/三种出身、共享长枪动作、6 装备栏、16 个装备定义、7 类有限触发效果、1–20 级、先锋与统帅流程。它仍是开发原型：界面和逻辑检查不等于完整三维战斗验收；三种出身还不是三套武器职业。

## v0.2 — 横屏适配（本次代码）
- 9:20 横过来即宽:高=20:9。统一 canvas、镜头、HUD、摇杆和菜单使用同一个安全区域矩形；其他比例等比留边，不拉伸人物、不 CSS 旋转点击面。
- 适配浏览器可视区域变化、安全边距和全屏。竖屏显示方向提示；战斗转竖屏暂停并清理输入，回到横屏后由玩家确认继续，不自动恢复受击。
- 界面留出中央战场；小屏行囊左右双栏，描述独立滚动，穿戴/淬炼/分解操作保留在可见区；次要配色/画质设置收进折叠区。
- 不改变敌人数、伤害、掉率、存档或上游 main/index.html；不新增广告或强制联网。

验收：目标比例与异形屏幕适配、触摸命中位置、旋转暂停/返回、菜单滚动与按钮可见性。真实手机及三维场景必须另测。

## v0.3 — 一局玩通与基础手感（下一优先级）
- 验证真实浏览器从创建→出征→清兵→爆装→拾取→暂停穿戴→先锋→主动挑战统帅→结算→刷新回营。
- 将首次获得装备的时间、第一次明显变强的时间、首领可挑战条件纳入记录；先做一张 5–8 分钟目标战役，而非盲目增加关卡。
- 首次 1–3 分钟应能获得有意义的新装备并感知伤害/攻击范围变化。时间是设计目标，不是本版测得结果。
- 手感重点：轻击接重击、突刺开路、击飞、闪避意图与镜头。弱小时能清小兵，强大后明显更快；不能把前期做成磨血。
- 同设备、同兵力、相近实际渲染分辨率比较原版和新模式，定位新增开销；优先保住大战场，不预先砍人数。

## v0.4 — 武器与装备构筑
- 先做真正不同的长枪/大刀/双刃三种武器动作；出身影响起点，武器决定招式，不用换名字冒充新职业。
- 首发先成立三种构筑：旋锋清兵、重击引雷、冲阵续战。加强机制联动、拾取反馈和换装对比，不堆一屏无感属性。
- 装备的稀有度不代表必须自动换上：保留玩家对词条、伤害、范围、防御和续航的取舍。
- 等级/装备成长不得让所有普通兵同步无限变硬。主角的强大用清兵能力体现，精英与统帅承担战术挑战。
- 追加效果有预算、冷却和来源标记；伤害动画与判定一致，避免递归连锁淹没战场。

## v0.5 — 大战场和统帅体验
- 在保留双方军队交战基础上，让营门、军旗、先锋和侧路形成可读目标；击败关键敌将后能看到友军推进。
- 地图保持连贯，不频繁切空房打 Boss；首领预警清楚，招式能靠走位/闪避处理。
- 奖励路线给予主动选择：继续刷装、援救友军、夺取补给，或提前挑战统帅。
- 先完成一张完整战场，再考虑第二张图与多种战役事件；不同时铺开开放世界、城建和军团管理。

## v0.6 — 水墨美术与移动性能
- 程序化主角、普通小兵、装备外观、纸白地形和墨色树木统一，不仅套滤镜；多人群动作的辨识度优先于华丽后处理。
- 优先新增一个成熟小兵母版与两三种轮廓；保留批量渲染/LOD，控制新材质和特效开销。
- 以相同战斗条件验证持续游玩、爆发和热机；验证声音、停顿、击飞与掉落反馈。
- 原版/水墨对照、长时内存与重进战场回收、Android/iOS 浏览器及目标平台容器分别验收。

## v0.7 — 小规模测试与平台接入
- 玩家测试记录：第一次换装、第一次理解构筑、失败原因、首领挑战时机、再次出征意愿。
- 检查发布平台接入要求后再接登录/广告等 SDK；首版不把付费强化和强制广告放在核心循环里。
- 当前 localStorage 不可信且无云端同步；任何可信排行榜/付费经济都要单独设计服务端校验，不直接沿用本地数据。

以上是按优先级排列的里程碑，不是后台自动开发承诺或固定日期排期。每阶段先验收可玩结果，再扩大内容量。
