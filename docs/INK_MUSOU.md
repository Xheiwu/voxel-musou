# 水墨三国动作版 · 第一阶段原型

本分支基于 BubuAi 的 Voxel Musou，保留原有 MIT 许可和署名。
定位：玩家亲自操控武将的横屏战场动作游戏，不改成自动攻击的站桩幸存者。
本次没有替换角色模型、战役、技能数值，也没有接入 TapTap SDK。

## 本次已修改

- 输入层增加多指触屏：左侧摇杆，右侧普攻、蓄力、闪避、无双；保留跳跃和镜头回正以免破坏原有招式。
- 普攻按住时每 12 个模拟步发送一次普攻按下信号；蓄力按住时暂停这项自动重复。其他动作不自动连发。
- 空白战场可拖动镜头，触摸不会被错误地当作鼠标攻击或请求鼠标锁定。
- 暂停、切换场景、失焦、触摸取消会清理输入；快速点按保留到下一个模拟步。
- 修复手柄按住状态没有写入 held，以及两个按键同时绑定闪避时释放其中一个会互相影响的问题。
- 增加可选水墨渲染：浅纸底、深度轮廓、远景淡化、少量红色/青色保留。
- 原 src/post/post.js 按原 blob 原样保存为 cinematic.js。默认继续使用原版渲染，水墨必须显式开启。

## 本地运行

在仓库根目录运行静态 HTTP 服务，例如 `python -m http.server 8000`，然后在浏览器访问。
不能直接双击 index.html 使用 file://；项目包含 ES 模块。

- 默认：`http://localhost:8000/`，原版画面，触屏设备自动显示操作按钮。
- 水墨实验：`http://localhost:8000/?style=ink`。
- 直接进入练习战场：`http://localhost:8000/?style=ink&go=free&char=zhaoyun&enemies=160`。
- 电脑模拟触屏布局：追加 `&touch=1`；禁用触屏：`&touch=0`。
- 水墨低画质：追加 `&quality=low`；支持 medium / high。`hq` 只关闭动态降分辨率，不改变质量档位上限。
- 输入调试页：`/checks/ink-input.html?touch=1`。此页只有控制器，不是战场预览。
