# 水墨演武 · 第二阶段优化

基于 `feat/ink-musou-h5` 的 `8a2cca3`，沿用原项目 MIT 许可及署名。改动不合并 main。

## 已接入

1. **输入意图优先级**：同一步输入中，重击、闪避、无双优先于普攻。触屏快速重击后，自动普攻暂停发送 54 个模拟步，保护原连招系统 WAIT(40)+BUF(14) 的缓冲窗口；重新明确按下普攻可解除该保护。不改原招式允许取消的时机，不声称任何时刻点重击都能出招。
2. **移动端界面重新排布**：左上角独立紧凑血条/无双槽；右上小地图和暂停；右下四个主要动作及两枚至少 44px 的辅助按钮。原“蓄力”按钮标为“重击”，更贴近普攻后的派生招式。320px 宽竖屏单独排布小地图，避免遮住血条。
3. **半俯视战场镜头**：默认俯角 35 度、距离 9.6、视场角 46 度。保留原镜头模拟、移动坐标、回正与目标辅助；视图叠加平滑跟随、遮挡缩进和地面保护。无双及黄忠瞄准期间回到原演出镜头。原相机完整保存为 `src/camera/classic.js`（同原 blob `43bc2c6ae5c2accc8c15381f2755d2059c77ddf7`）。
4. **非体素赵云原型**：参数化曲面、锥形铠甲、青色束带、简化头盔与枪刃，22 个合并部件，总计 2780 个三角形（不含披风）；挂接原骨架，沿用原攻击动画、技能数值和武器轨迹。另有简化程序披风。仅 `models=ink` 开启，不会替换其他武将、小兵或地图。
5. **水墨兼容与预热**：检查浮点颜色附件支持及 framebuffer 完整性；失败尝试 RGBA8/无多重采样。原场景和水墨合成材质都进入预热。RGBA8 是兼容画质，颜色不保证与 HDR 完全一致。WebGL2/缓冲初始化失败有可读提示，图形上下文丢失时暂停并提示等待恢复。
6. **性能检测**：`perf=1` 显示帧间隔中位数/P95、平均 FPS、整帧绘制次数/三角形数、纹理/几何数、实际渲染分辨率和缓冲格式。包括场景及合成两次 render，非 GPU 计时。动态分辨率使用连续慢帧持续时间而不是固定帧数；暂停、隐藏或长停顿不触发误降级。不调整敌人数、模拟步长或战斗判定。
7. **实验入口**：仓库静态服务的 `ink.html` 可选择 80/160/300 敌军、画质、赵云新模型和性能检测，不需要手写 URL 参数。

## 如何查看

运行整个仓库的静态 HTTP 服务，例如 `python -m http.server 8000`，然后打开 `/ink.html`。
需要 HTTP 服务与完整仓库，不是双击本地 HTML，也不是 GitHub 的源码查看页。
本次没有创建外网部署，README 里的原作者演示地址不会反映本分支改动。

手动入口：

```text
/index.html?style=ink&camera=battle&models=ink&go=free&char=zhaoyun&enemies=160&perf=1
```

- 原镜头：`camera=classic`；半俯视：`camera=battle`（`tactical` 亦可）。水墨模式或触屏设备默认用半俯视，其余原版桌面不变。
- 去掉 `models=ink` 恢复原赵云造型，其他角色一直沿用原模型。
- `touch=1/0` 强制显示/禁用触屏控制；画质中的触屏判定也尊重这个参数。
- `quality=low/medium/high`，`hdr=0` 强制兼容颜色缓冲以便测试，`hq` 固定分辨率档位。
- 练习模式保持原有不死亡、不记录战役通关规则。
